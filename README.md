# Уведомления в Telegram (P3.3)

Функция `notify` рассылает уведомления из очереди `notifications` в Telegram. Очередь наполняется автоматически: при изменении готовности вехи проекта триггер `on_milestone_change` (см. `supabase/schema.sql`) ставит сообщение ответственному участнику.

## 1. Создать Telegram-бота

1. Открыть в Telegram чат с **@BotFather**.
2. Отправить команду `/newbot`, задать имя и username бота (username оканчивается на `bot`).
3. BotFather выдаёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Это и есть токен бота.
4. Вставить токен в платформе: раздел «Администрирование» → «Интеграции» → поле «Telegram bot token» → «Сохранить реквизиты». (Либо задать переменную окружения `TG_BOT_TOKEN` у функции, см. п.4.)

## 2. Получить chat_id участников

Уведомление уходит на `telegram_chat_id` профиля. Как узнать chat_id:

1. Участник открывает чат с ботом и отправляет ему любое сообщение (например, `/start`).
2. Открыть в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найти `"chat":{"id":...}`. Это число и есть chat_id.
   (Альтернатива: бот `@userinfobot` показывает chat_id пользователю.)
3. Администратор вписывает chat_id в столбец «Telegram chat_id» таблицы пользователей (раздел «Пользователи и роли»).

Без заданного chat_id уведомление остаётся в очереди со статусом «ошибка» и понятной причиной.

## 3. Демо-режим (LocalAdapter)

В демо-режиме (без Supabase) отправка идёт прямо из браузера через Bot API: кнопка «Отправить очередь» в разделе «Уведомления». Достаточно токена бота и заполненных chat_id. Serverless-функция не нужна.

## 4. Production-режим (Supabase)

1. Установить Supabase CLI и войти: `supabase login`, `supabase link --project-ref <ref>`.
2. Развернуть функцию:

   ```
   supabase functions deploy notify --no-verify-jwt
   ```

3. (Необязательно) задать токен как секрет функции, если не хранить его в настройках платформы:

   ```
   supabase secrets set TG_BOT_TOKEN=123456789:AAE...
   ```

   `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` Supabase подставляет автоматически.
4. Кнопка «Отправить очередь» в админ-панели вызывает функцию (`supabase.functions.invoke('notify')`). Для автоматической рассылки настроить cron (Dashboard → Database → Cron) с вызовом функции по расписанию.
