# Платформа консорциума «ЭнергоЦОД»

Онлайн-платформа кооперации участников рынка ЦОД и энергоцентров: каталог активов, карта размещения, конфигуратор проекта с финансовой моделью, заявки и проекты с вехами, реестр участников, база НПА, журнал результативных контактов и уведомления. Тёмная тема, русский интерфейс (EN/中文 для навигации), работа как в демо-режиме (без бэкенда), так и на Production-бэкенде Supabase.

## Быстрый старт (демо-режим)

Открыть `index.html` в браузере (двойным щелчком или через локальный сервер). Бэкенд не нужен: данные хранятся в браузере (LocalAdapter, localStorage). Демо-профили создаются автоматически, общий пароль `energocod`. Вход администратора: `admin@energocod.ru`.

Демо-режим предназначен для тестовой среды. Все данные лежат в браузере и видны только на этом устройстве.

## Архитектура

Фронтенд — SPA на ванильном JS без сборки и без фреймворков, обычные скрипты (не ES-модули), чтобы платформа открывалась прямо с диска (`file://`). Подробности в `docs/ARCHITECTURE.md`.

Ключевой принцип — слой данных как адаптер. Все модули обращаются к данным только через фасад `DB.*` (`src/db.js`). Реализаций две:

- `LocalAdapter` — localStorage, работает сразу, демо-режим.
- `SupabaseAdapter` — Production-бэкенд (Postgres + Auth + RLS), активируется администратором в разделе «Интеграции» вводом URL и anon-ключа, без правки кода.

Все изменяемые параметры (веса скоринга, диапазоны и значения бегунков, расчётные константы, шаблон вех, реквизиты интеграций) хранятся в версионируемых настройках и меняются администратором в интерфейсе.

## Структура

```
platform_v4/
  index.html              точка входа, порядок подключения скриптов
  styles.css              тёмная тема
  src/
    data.js               статические данные и геоданные
    db.js                 слой данных: LocalAdapter, SupabaseAdapter, фасад DB
    i18n.js               интернационализация (ru/en/zh)
    app.js                каркас: состояние, маршрутизация, инициализация
    views/                представления по вкладкам (dash, assets, calc,
                          deals, milestones, npa, map, members, auth, admin)
  i18n/{ru,en,zh}.json    словари интерфейса (документируемый источник)
  supabase/
    schema.sql            схема Postgres + RLS + триггеры (выполнить один раз)
    functions/notify/     edge-функция рассылки уведомлений в Telegram
  tests/smoke.test.js     смоук-тест слоя данных (node tests/smoke.test.js)
  docs/                   ARCHITECTURE, ADMIN_GUIDE, DEPLOY_GUIDE, TEST_CHECKLIST
```

## Тестирование

Смоук-тест логики слоя данных:

```
node tests/smoke.test.js
```

Ручная проверка экранов по ролям и языкам — `docs/TEST_CHECKLIST.md`.

## Развёртывание

Пошаговая инструкция (GitHub Pages + Supabase, Telegram-бот) — `docs/DEPLOY_GUIDE.md`. Руководство администратора — `docs/ADMIN_GUIDE.md`.
